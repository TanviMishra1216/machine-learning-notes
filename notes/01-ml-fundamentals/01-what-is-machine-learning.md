Machine Learning is the branch of AI where computers use data to find patterns and make predictions. Instead of giving it seperate rules for every possible situation, we provide it with a few examples that it uses to build a generalized model. 

data -> learning algorithm -> model -> prediction

example: if we need a computer to classify spam emails, we can give it many examples of spam and non-spam emails. 

using those examples, the computer learns patterns and uses them to classify any new emails.
